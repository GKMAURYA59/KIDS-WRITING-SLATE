## My Writing Slate

A digital writing slate for children. They can write, draw and trace letters on a chalkboard-style screen with a finger, stylus or mouse. It is built for phones and tablets and is a single HTML file with no installation needed.

Live demo: https://gkmaurya59.github.io/writing-slate/

## Features

Chalkboard slate to write and draw on
8 big colour buttons and 3 pen sizes (thin, medium, thick)
Eraser and Undo
Clear button that needs two taps ("Tap again to clear"), so a drawing is not wiped by accident
Save button that downloads the picture as my-slate.png
Trace letters: a dotted outline of a big letter to trace, with arrow buttons to move between letters
Full screen button for more room on a phone or tablet
Works offline once loaded
## Buttons
Button	What it does
Colour circles	Choose the pen colour
Small, medium and large dots	Choose the pen size
Eraser	Rubs out drawing (tap again to go back to the pen)
Undo	Removes the last stroke
Clear	Wipes the slate (tap twice)
Save	Downloads the drawing as a PNG picture
Full screen	Hides the browser bars (shown as Exit full screen while on)
Trace letters	Shows a dotted letter to trace, with arrows to change it
Parent options

## Tap Parent options at the bottom of the page to change:

Board: chalkboard or whiteboard
Paper: writing lines, grid or plain
Letters: ABC, abc or 123
Install on Android
Open the live demo in Chrome on the phone or tablet.
Tap the ⋮ menu (top right), then Add to Home screen (or Install app).
Confirm. The slate now opens from the home screen like an app.

This is a web app, not a native Android app, so it opens through the browser.

## Run locally

There is nothing to install and no internet connection is needed. Download index.html and open it in any modern browser.

## Built with

HTML, CSS and plain JavaScript (canvas) in a single file.
